# Διαδραστική Μαθησιακή Εφαρμογή Μαθηματικών (Interactive Learning App)

Αυτή η εφαρμογή είναι μια διαδραστική πλατφόρμα μάθησης και εξάσκησης στα Μαθηματικά (Αριθμητικές Παραστάσεις & Πράξεις) σχεδιασμένη για μαθητές. Είναι υλοποιημένη σε Python με τη χρήση **Streamlit** για τη διεπαφή χρήστη και **SQLite** για τη διαχείριση της βάσης δεδομένων.

---

## 🚀 Χαρακτηριστικά (Features)

- **Βάση Δεδομένων SQLite (`exercises.db`)**: Αποθήκευση και διαχείριση ασκήσεων ανά κεφάλαιο.
- **Αυτόματη Εγκατάσταση/Ενημέρωση (`db_installer.py`)**: Ανάγνωση του `questions.json` και εισαγωγή/ενημέρωση (upsert) των ασκήσεων στη βάση δεδομένων.
- **Φιλικό UI με Streamlit (`app.py`)**:
  - Φιλτράρισμα ασκήσεων ανά Κεφάλαιο.
  - Υποστήριξη ερωτήσεων Πολλαπλής Επιλογής (Multiple Choice) και Ελεύθερου Κειμένου/Αριθμού.
  - **Άμεση Ανατροφοδότηση (Instant Feedback)** με κουμπί «Αποστολή / Έλεγχος»: Εμφάνιση επιτυχίας ή αναλυτικής βήμα-προς-βήμα λύσης (`explanation`) σε περίπτωση λάθους.
  - **Πρόοδος & Σκορ**: Μπάρα προόδου (π.χ. Ερώτηση 3/10) και ζωντανή καταμέτρηση σκορ.
  - Πλοήγηση μεταξύ ερωτήσεων και δυνατότητα επανεκκίνησης κεφαλαίου.

---

## 🛠️ Εγκατάσταση (Installation)

### 1. Απαιτήσεις
Βεβαιωθείτε ότι έχετε εγκατεστημένη την Python (έκδοση 3.8 ή νεότερη).

### 2. Εγκατάσταση εξαρτήσεων
Εγκαταστήστε τις απαιτούμενες βιβλιοθήκες εκτελώντας:

```bash
pip install -r requirements.txt
```

---

## 🗄️ Εγκατάσταση / Ενημέρωση Βάσης Δεδομένων

Για να δημιουργήσετε τη βάση δεδομένων `exercises.db` και να εισαγάγετε τις ασκήσεις από το `questions.json`, τρέξτε:

```bash
python3 db_installer.py
```

---

## 💻 Εκτέλεση Εφαρμογής (Streamlit App)

Εκκινήστε την εφαρμογή Streamlit με την παρακάτω εντολή:

```bash
streamlit run app.py
```

Η εφαρμογή θα ανοίξει στον περιηγητή σας (συνήθως στη διεύθυνση `http://localhost:8501`).

---

## 🧪 Εκτέλεση Unit Tests

Για να εκτελέσετε τα αυτόματα τεστ (για τη βάση δεδομένων και τη φόρτωση JSON):

```bash
python3 -m pytest
```
